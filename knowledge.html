1. 什么是股票与A股

股票是股份公司签发的所有权凭证。买入一家公司的股票，你就成为它的股东，享有分红权和（部分股票的）投票权，同时也承担公司经营与股价波动的风险。

A股指在中国内地注册、在境内证券交易所上市、以人民币普通股形式交易的股票。目前A股有两个主要交易所：

  • 上海证券交易所（上交所，SSE）：股票代码多以 6 开头（如 600、601、603、688 科创板）。
  • 深圳证券交易所（深交所，SZSE）：股票代码多以 0 或 3 开头（000 主板、002 中小板并入主板、300 创业板）。

此外还有北京证券交易所（北交所），代码以 8 开头，主要服务创新型中小企业。

A股散户（个人投资者）占比高，情绪波动大，涨跌往往比成熟市场更剧烈，新手更要重视风险控制。

2. 开户与交易规则

2.1 如何开户

  1. 选择一家正规券商（证券公司），下载其官方App。
  2. 准备身份证、银行卡，完成实名认证、风险测评、视频见证。
  3. 绑定银行卡（第三方存管），即可入金交易。

一个投资者在同一市场（沪/深）只能各开一个A股账户，但可以在多家券商开立资金账户。

2.2 核心交易规则

规则说明
交易时间周一至周五 9:30–11:30、13:00–15:00；集合竞价 9:15–9:25、14:57–15:00。
T+1 交易当天买入的股票，第二个交易日才能卖出。当天卖出的资金可继续买，但取现需 T+1。
涨跌停限制主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST 类股票多为 ±5%（主板）。新股上市首日另有规则。
最小交易单位买入以「手」为单位，1 手 = 100 股（科创板可 200 股起）。卖出可不足 100 股（零股）。
交易成本佣金（约万 1–万 3，有最低 5 元限制）、印花税（卖出时 0.05%）、过户费（沪市约 0.001%）。
新手要点：频繁交易会被佣金和印花税慢慢"吃掉"收益。低买高卖听起来简单，实际极难，先少交易、多学习。

3.1 各板块特征

板块代码涨跌停特点与门槛
沪深主板600/000/002±10%规模较大、相对成熟，无资金门槛。

科创板688±20%硬科技企业，需开通权限（50万资产+2年经验）。
北交所8开头±30%创新型中小企业，需开通权限。
ST/*ST—±5%被风险警示，可能退市，新手建议回避。

3.2 常见可投资品种

  • 股票：直接买入公司股权，波动最大。
  • 指数基金/ETF：一篮子股票，分散风险，费用低，最适合新手起步。
  • 可转债：债券+转股权利，"下有保底、上不封顶"（相对而言），但有强赎等风险。
  • 货币基金/国债逆回购：低风险现金管理工具，适合存放暂时不用的资金。
新手建议：起步阶段用宽基指数基金定投（如沪深300、中证500），先感受市场波动，再逐步配置个股。

4. 看懂K线与行情

4.1 一根K线包含四个价格

K线（蜡烛图）记录一段时间内的开盘价、收盘价、最高价、最低价：

  • 收盘价 > 开盘价：阳线（红），表示上涨。
  • 收盘价 < 开盘价：阴线（绿），表示下跌（A股习惯红涨绿跌）。
  • 实体上下的小细线叫影线，反映盘中冲高/探底后的回落。

4.2 成交量与分时图

  • 成交量（量）：成交的股票数量。放量上涨通常代表资金积极，缩量下跌代表抛压减轻但也可能无人接盘。
  • 分时图：当天每分钟的价格走势，配合均价线判断强弱。
  • 量价配合是判断趋势是否健康的重要依据：价涨量增 = 健康；价涨量缩 = 需警惕。
新手要点：不要只看单根K线做决定。结合趋势、位置和成交量一起看，避免被单日"假动作"骗。

5. 基本面与财报

基本面分析回答一个问题：这家公司本身值不值这个价？核心是读三大财务报表。

报表回答的问题重点科目
利润表赚不赚钱营业收入、净利润、毛利率、净利率
资产负债表家底厚不厚、风险大不大总资产、负债率、现金流、商誉
现金流量表赚的是不是"真钱"经营活动现金流净额

5.1 四个关键判断

  • 营收与净利润增长：是否持续增长，增长来自主营还是"卖资产"等一次性收益。
  • 经营现金流：最好与净利润匹配甚至更高。若净利润很高但现金流常年为负，要警惕财务造假。
  • 负债率与商誉：负债过高、商誉过大（高溢价并购）都有减值暴雷风险。
  • 毛利率与ROE：毛利率高说明有定价权；ROE（净资产收益率）长期 >15% 通常是好生意的信号。
财报数据可在巨潮资讯网、交易所官网或各行情软件免费查看，注意区分年报/季报与业绩预告。

6. 估值指标

估值回答：现在贵不贵？常用指标如下。

指标含义用法
市盈率 PE股价 / 每股收益越低回本越快，但要对比行业和成长性
市净率 PB股价 / 每股净资产适合银行、地产等重资产行业
PEGPE / 净利润增速<1 常被认为成长与估值匹配
股息率每股分红 / 股价衡量现金回报，适合稳健型投资者
新手要点：低PE不等于便宜（可能是行业衰退），高PE不等于贵（可能是高成长）。要同行业横向比、和自己历史纵向比。

7. 技术分析入门

技术分析研究价格的走势规律，帮你判断买卖时机。常见工具：

  • 均线（MA）：MA5、MA20、MA60。股价站上均线、均线多头排列通常偏强；跌破关键均线要警惕。金叉/死叉是常用信号。
  • MACD：判断趋势与动能，零轴上方偏多，金叉/死叉 + 背离是重点。
  • KDJ / RSI：超买超卖指标，>80 可能超买，<20 可能超卖，但强趋势中会"钝化"，不能单独用。
  • 支撑与压力：前期高低点、成交密集区常成为价格的支撑位或压力位。
  • 形态：头肩顶/底、双底、突破等，用于辅助判断趋势转折。
重要提醒：技术指标都是概率工具，不是预测水晶球。任何"必涨形态"都不可信，务必结合基本面与风险控制。

8. 消息面与政策

A股受政策与消息影响较大，关注三类信息：

  • 宏观政策：货币政策（降息降准）、财政政策、GDP/CPI/PMI 等经济数据。
  • 行业政策：产业扶持或监管收紧，往往带来板块级行情。
  • 公司公告：业绩预告、重大合同、增发、大股东减持、重组等，是股价直接催化。
信息渠道要有权威性：交易所公告、巨潮资讯、权威财经媒体。远离"荐股群""内幕消息"，多数是骗局。

9. 风险管理（最重要的一章）

市场里活得久，比赚得快更重要。四条铁律：

  1. 仓位管理：永远不要满仓单一股票。可用"金字塔"分批建仓，单只个股不超过总资金的 10%–20%。
  2. 止损止盈：买入前就设好止损位（如亏损 8%–10% 无条件离场），并严格执行，避免小亏拖成大亏。
  3. 分散投资：跨行业、跨品种分散，降低单一事件冲击。
  4. 只用闲钱：绝不借钱、加杠杆、动用生活费和救命钱投资。
心态提醒：贪婪与恐惧是散户最大的敌人。不要追涨杀跌，不要因为"回本"而死扛。制定计划，然后按计划执行。

10. 新手常见误区

误区真相
追涨杀跌、听消息买股热点往往在你听说时已接近尾声，容易高位接盘。
All in 一只"翻倍股"重仓单一个股，一次黑天鹅就可能重创本金。
亏损死扛、盈利就跑截断利润、放跑亏损，是长期亏损的核心原因。
频繁短线交易交易成本 + 情绪消耗，长期跑输大盘。
迷信"内幕/荐股"正规渠道不会向你承诺收益，此类信息多为骗局。
